## 4. 作り方の推測 (3 グループ)

判断の手がかり:
(a) 台詞が短く定型的で、台本間で同文の行が多い (同じ入力で決定的に近い生成が行われた形跡) → 1 行ずつ生成。
(b) 全員が毎ターン揃って 4 ターン話し、「Over」の行が別行で混じらず、全体の弧がきれい。案が公開前に話題へ出る (台本全体を見ている書き手のような振る舞い) → 全文一括。
(c) 「発言した直後に同じターンで Over」「参加者ごとに離脱ターンがずれる」「票が自分の発言と合わない」「占い先が台本ごとに違う」など、各人が独立に動いた痕跡 → 参加者ごとに別モデル。

| 設定 | 1 行ずつ (推定) | 全文一括 (推定) | 参加者別 (推定) |
|---|---|---|---|
| aiwolf | A, E, C | B, G | D, F |
| candidate_selection | A, C, F | B | D, E, G |
| shared_living | B, G, C | A, D, E | F |

根拠:
- aiwolf A と E は Day 0 全 14 行が一字一句同じで、Day 1 でも Benjamin・Kenji の行が一致する (Mizuki の 1 行だけ差がある)。1 行ずつ、ほぼ決定的な生成で同じ文脈から出た形跡。C も短く似た骨格。
- candidate_selection A と C は Round 1 の 5 行がほぼ同文。shared_living B と G も Round 1・Round 2 の大半が同文 (C も近い)。同じ作り方の短い台本が各設定に 2〜3 本ずつある。
- aiwolf B と G は、Day 0 が全員の就寝挨拶で終わり、Over が付かず、人狼が自票という共通点がある。一括生成で、結末に向けて筋を整える書き方に見える。candidate_selection B は Over/Skip がなく全員が毎ターン発言する。shared_living A・D・E も同様。
- aiwolf D は Day 0 の最終ターンで「発言→Over」の 2 行を出す人が混じり、占い師が初日に Kenji を占うなど、役職ごとの独立した判断がある。F も、Minako→Mizuki など票が発言と無関係。candidate_selection D・E・G は離脱ターンがずれ、shared_living F も最終ターンで 2 人は発言し 3 人は Over のみ。参加者ごとに別の呼び出しがあったと考えると自然。
- 確信度は中程度から低い。1 本だけ孤立する設定 (cand B、shared F) があり、群の境界は曖昧。ラベルが設定間で対応しているかも不明で、グループ分けは設定内の比較にとどまる。

## 5. 長さによる影響の自覚

- あった。長い台本 (aiwolf D・F、cand D・E・G、shared D・E・F) は、論点の幅や口調の違いで D・R・P を高く付けやすく、短い台本 (aiwolf A・E、cand A・C、shared B・G) は L・R・D を低く付けやすかった。短い台本は漏れの機会が少なく、I が高めに出る傾向もある。
- 補正として、(1) 長くても同じ宣言を繰り返す台本 (cand G、aiwolf G) は D を低くし、(2) 短くても少数意見や根拠のある対立がある台本 (shared C の Asuka、aiwolf E の Kenji) は評価を下げなかった。ただし完全な補正はできておらず、本評価では長さを揃えるか、長さを共変量として扱う必要がある。
