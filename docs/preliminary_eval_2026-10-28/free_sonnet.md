定性的な印象です。鍵ファイルは読んでいません。

## 1. aiwolf_0001 (5 人村: 占い師 Benjamin / 人狼 Shizue / 狂人 Kenji / 村人 Mizuki, Minako)
### Transcript A
- 所見: 初日の Day 0 は 2 ターン分の定型挨拶の後 Skip と Over だけ。Day 1 は Benjamin のカミングアウトから処刑まで 4 ターンで終わる。発話は 1 文程度と短く、筋は通るが肉付けがほぼない。
- 目立った点: 筋の通りは良い (カミングアウト、反論、「高リスクの人狼なら名乗らない」という推論、投票)。応答も直前の発言に沿う。
  ただし Minako の「Benjamin、占い師を名乗っているのか」は、Benjamin が占い師とは言っていない段階の発言で、少し先走る。
  対立は Kenji の「でも嘘かも」が唯一で、浅い。人物の一貫性は保たれている。
### Transcript B
- 所見: Day 0 は全員が長く話し、Day 1 は占い師を名乗らないまま「Shizue の穏やかさは出来すぎ」という行動分析だけで処刑に至る。Kenji と Shizue の「相互擁護ループ」を村側が指摘する流れは人狼らしい。
- 目立った点: 直前発言への応答は最も細かい (Minako が Mizuki と Benjamin の疑いを要約して Shizue に振る)。対立は Kenji と他全員の間で自然に育つ。
  欠点は 2 つ。
  - Benjamin は結果を知っているのに最後まで名乗らず、ほのめかすだけ。占い師としては不自然。
  - Kenji は「自分に投票してでも」と言いながら Shizue に投票し、発言と投票が食い違う。Shizue の自己投票もやや不自然。
### Transcript C
- 所見: 短めで、Day 0 に「占い師が出たら聞く」という約束が入る。それが Day 1 の Benjamin のカミングアウトにつながる。短いが応答のつながりが良い。
- 目立った点: Mizuki が「Kenji の反射的な擁護が気になる」と返し、Minako が「Kenji の擁護は人柄の話で論理ではない」と返すなど、論点の絞り方が的確。
  Benjamin の「早く名乗ったのは人狼に襲われないため」という理由付けも自然。
  Kenji の「彼女は震えている!」は、台本上は見えないはずの描写で、軽い違和感がある。
- 人物の一貫性は良い。投票も発言と一致する。
### Transcript D
- 所見: 唯一 2 日目まで進み、人狼が勝つ。Benjamin (占い師) は Kenji を占って白だったが名乗らず、Day 1 に Mizuki が「傍観者的で怪しい」と Benjamin を攻めて処刑される。
- 目立った点: 情報が乏しい日に、立場の不明な人物へ疑いが集まる過程が自然。Mizuki と Benjamin の応酬は上品な口調のまま噛み合っている。
  Day 2 の 3 人 (Shizue、Mizuki、Kenji) の会話も、「残りは Shizue か Kenji」という推論から Kenji の泣き言までキャラが一貫している。
  弱点は 2 つ。
  - 占い師が名乗らずに吊られる点 (村としては下手だが、ゲームとしてはありうる)。
  - Mizuki の「反応を試すために票を入れる」という根拠の薄さ。
### Transcript E
- 所見: A とほぼ同一の文面 (Day 0 は一字一句同じ) で、Day 1 の細部だけが違う。短い。
- 目立った点: A より Mizuki が慎重で、Kenji が「投票に反対する」と言って本当に Benjamin に入れるので、発言と投票が一致する。
  一方、Minako の「Benjamin が人狼なら信頼されている長老を消そうとしている」は意味がやや曖昧。全体に薄い。
### Transcript F
- 所見: 長く、Day 2 まで進む。Benjamin は Day 1 に「Kenji は白」とカミングアウトする。村側が Benjamin を信じる流れの中、全員が突然 Mizuki に投票して処刑する。
- 目立った点: 重大な欠陥がある。Day 1 の会話では誰も Mizuki を疑っておらず、Benjamin を支持する流れなのに、投票だけ Mizuki に集中する。会話と投票が接続していない。
  ほかの点は良い。
  - Day 2 で Benjamin が Shizue を占って対抗する場面は筋が通っている。
  - Shizue の「目を見て」という情に訴える場面もキャラに合う。
- 知らないはずの情報: Benjamin の「雇われて欺く者もいる」は役職の存在を前提にした発言で、やや唐突。
### Transcript G
- 所見: 丁寧で整っているが、Day 1 は Benjamin のカミングアウトの直後に全員が同調し、対立はほぼ生まれない。
- 目立った点: 応答は適切で、Shizue の「微笑んで受け入れる」というキャラ一貫性も高い。
  ただし Minako と Mizuki が同じ主張 (反論できない = 黒) を繰り返して水増しされている。Shizue の自己投票は B と同じ違和感。

## 2. candidate_selection_0001 (審査員 5 人、候補 A〜D、各自が調べ物 2 件を非公開で得る)
背景の整理: 事実は Round 2 で各自が自分の調査結果として語るもの。次のとおり。

### Transcript A
- 所見: Round 1 と Round 2 の発言はコピーの多い短文。Round 3 は全員が早々に A に収束する。
- 目立った点: Benjamin は「A は野外サイトで危険」と言いながら A に投票する。Servas も A は野外と言い、「A か C」と述べる。反対意見がなく、収束の理由が薄い。
  Kenji の「リポジトリが速い」は Toshio の調査結果で、Round 2 で誰も共有していないのに Kenji が使っている。これは知らないはずの情報の使用にあたる。
### Transcript B

- 目立った点: 論点が筋よく進む。
  - Kenji が「Benjamin が野外は賭けだと言った」と出典付きで使う。

- 目立った点: Servas が「Protein か Atlas」と言い、Kenji が「Protein は分光が不安定」と反論し、Benjamin が「Atlas は繁殖リスクも分光不良も避ける」と応じる、という小さなやり取りがある。

### Transcript D
- 所見: 長く、文語的で雰囲気のある文体。Round 1 は全員が方針を語るだけで、Round 3 は最初のターンで全員が A を推し、残りは賛同の連呼になる。

## 4. 作り方のグループ分けの推測
確信は低いです (7 本ずつ、候補は 3 通りのみ想定)。
手がかりになったのは次の 5 点です。
- 文面のコピー (同じ文がほかの台本にも出る)
- 発言の長さと語彙
- Skip と Over の出方 (全員同時か、人ごとにずれるか)
- 事実や役職の扱い
- 発言と投票の整合
### 手がかりから見た 3 つの型
- 型 I「短文・コピー型」。文面が他の台本とほぼ同一で、短い。Skip と Over が全員同時に並ぶ。
  1 行ずつ (あるいは参加者ごとの短い呼び出しで) 低い温度で生成され、同じ前置きなら同じ文が出る、という作り方に見える。
- 型 II「長文・文語型」。全員が長く、「ghost (幽霊)」「facade (仮面)」のような同じ比喩を別々の人物が使う。
  Round 1 に挨拶や雰囲気のやり取りが多い。
  1 つのモデルが全文を一括で書いた、あるいは 1 つのモデルが全員分を逐次に書いた作り方に見える。
- 型 III「参加者別・非同期型」。Skip と Over が人ごとにずれ、「発言 + Over」の二重行が出る。
  占い師が情報なしで占う、といった参加者視点の判断がある。参加者ごとに別のモデル (または別の呼び出し) が書いた作り方に見える。
### aiwolf_0001

| グループ | 台本 | 根拠 |
|---|---|---|
| 1 | A, E (と近縁の C) | Day 0 が A と E で一字一句同じ。C も短く同じ型。型 I。 |
| 2 | B, G | 長文で文語的、Day 0 は全員の「おやすみ」で終わる。両方で Shizue が自己投票する (本人が人狼なのに)。型 II。 |
| 3 | D, F | Benjamin が情報なしで Kenji を占う (他の 5 本は初手で Shizue = 人狼を引き当てている)。「Possessed」や「雇われた欺き手」など役職を語る。2 日目まで進む。型 III 寄り。 |
A, B, C, E, G の 5 本は占い師が初日に人狼を引き当てており、筋を決めてから書いた (全知的な) 可能性がある。D と F は参加者視点に見える。

### 全体として
- 型 I は「事実は出すが交渉がない」、型 II は「掛け合いが先に立ち収束が早い」。
- 質の高い台本は、中程度の長さで自分の調査結果を丁寧に使うもの (candidate の B・E・F、shared の F・D)。長さと質は一致しない。
