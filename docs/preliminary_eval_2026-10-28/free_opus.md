## 1. aiwolf_0001 (Kenji=狂人, Mizuki/Minako=村人, Benjamin=占い師, Shizue=人狼)

### 台本ごとの所見

## 4. 作り方の推測とグループ分け

台本の文字は設定ごとにシャッフルされているようなので、グループは設定ごとに書く。

### グループ I: 1 つのモデルが全文を一括で書いた (確信度: 高)
- aiwolf **A, C, E** / candidate **A, C, F** / shared **B, C, G**
- 根拠:
  1. 発話が 1 文程度に揃っている。
  2. **全 5 人が同じターンで一斉に Skip、次のターンで一斉に Over する**。これは各発言者が独立に判断していればほぼ起きず、作者がターン単位で行をまとめて書いた跡に見える。
  3. 収束が速く、全会一致が多い。
  4. **知らないはずの情報の漏れがこのグループに集中している** (candidate A と F の Kenji、shared B の Shunichi)。全員の情報を 1 つの文脈に持つ書き手ならではの誤り。aiwolf では 3 本とも占い先が真狼の Shizue で、作者が配役を知っていることとも整合する。
- 下位区分: 各設定に「途中まで逐語的に同じ」ペアがある (aiwolf A/E、candidate A/C、shared B/G)。分岐は 3 設定とも**私的情報の開示直後** (占い結果のあと / Round 1 の調査結果のあと) に起きている。同じモデル・同じプロンプトで決定的にデコードし、条件差が私的情報の与え方やその後の扱いにだけ現れる 2 条件だと推測する。残りの 1 本 (aiwolf C、candidate F、shared C) は冒頭から文面が違い、プロンプトが別の変種 (シナリオ情報の有無など) と見る。

### グループ II: 発話を 1 行ずつ (話者ごと・ターンごとに) 生成した (確信度: 中〜高)
- aiwolf **B, D, F, G** / candidate **B, D, E, G** / shared **A, D, E, F**
- 根拠:
  1. 発話が 2〜3 文と長く、字数がほぼ一定。1 発話ごとに長さの指示を受けた出力に見える。
  2. Skip と Over が個人ごとにばらばらに出る (candidate B の Servas、D の Toshio、shared A の Rin、shared F の終盤)。
  3. **同じターン内で「発言」と「Over」が 2 行続く** (aiwolf D、candidate D・E・G)。一括で書く作者はこうは書かず、1 回の行動出力に発言と離脱が同居した跡に見える。
  4. 「このターンはもう言うことがない」というメタ発言 (candidate G、shared A の Asuka)。
  5. 漏れがほとんど見つからない。
- 下位区分 (確信度: 低〜中):
  - **II-a 参加者ごとに情報を分けて生成** (各自が自分の役職と情報しか持たない): aiwolf **D, F** がもっとも強い候補。占い師が人狼でない Kenji を占い、人狼も CO 済みの占い師を噛まず、F では議論と無関係な票が集まり、D では人狼が勝つ。どれも「全員の内心を知る作者」なら書きにくい。candidate と shared では、candidate **D** (互いの調べ物を調整できず Toshio が重複) と **E**、shared **D** と **F** (情報が本人の範囲に厳密に収まり、結論がほかと違うか、検討の跡がある) を推す。
  - **II-b 1 つのモデルが全員の情報を見ながら 1 行ずつ書いた**: aiwolf **B, G**。Day 0 の文面は D や F とほぼ同じ (Minako・Mizuki・Benjamin の冒頭、Kenji のおやすみの挨拶が一致) で、生成器の口調は共通。一方で、村人が根拠なしに真狼を名指しする、人狼が演出的に自分へ投票する、といった作者的な全知の痕跡がある。candidate **B, G**、shared **A, E** もこちらと推測するが、根拠は「整いすぎ・予定調和」という印象程度で弱い。
- **参加者ごとに別々の LLM** という可能性について: 7 本とも話者間の文体差は人物像の差だけで、語彙・構文の癖 (「A most prudent approach」「I shall be observing with equal curiosity」など) は全話者・全台本で共通。別モデルを混ぜた痕跡は見えない。参加者を分けた条件があるとしても、同じモデルを参加者ごとに別々に呼び出した形だと考える。

### 品質との関係 (印象)
- 順位の上位はグループ II が占めた (aiwolf D・G・F、candidate E・B・D、shared F・D・E)。下位はグループ I。
- ただし II では人物像の揺れ (shared E の May、aiwolf D の Kenji) と、議論と投票のずれ (aiwolf F、shared D) が出る。I は筋は通るが薄く、漏れが出る。
- 本評価では「漏れ」と「議論と投票の整合」を独立の軸として採点するのが有効そう。一斉の Skip/Over はそれだけで生成方式が分かる手がかりなので、盲検性を保つなら評価前に正規化を検討したほうがよい。
