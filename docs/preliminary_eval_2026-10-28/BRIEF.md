# 予備評価 (preliminary, qualitative) のブリーフ — 2026-10-28

目的: 本評価の設計の前に、条件ごとの議論台本がどう違って見えるかの「感覚」を得る。論文には使わない。条件名は伏せてある。

材料: このディレクトリの bundles/<setup_id>.md。各ファイルは同じ設定 (同じ議題・同じ参加者・同じ配役) で生成された 7 本の台本
(Transcript A〜G) を `---` で区切って並べたもの。台本の文法は共通 (## Day / ### Talk / #### Turn t of 4 / - **名前**: 発話 /
### Vote / ### Action / ## Result)。`Skip` はそのターンをパス、`Over` はそのラウンドから離脱。

設定の背景:
- aiwolf_0001: 5 人村の人狼ゲーム (占い師 1、人狼 1、狂人 1、村人 2)。Kenji = 狂人、Mizuki = 村人、Benjamin = 占い師、Shizue = 人狼、Minako = 村人。
- candidate_selection_0001: 生命科学の国家助成の採択課題を 4 候補 (A〜D、Round 3 で公開) から 1 つ選ぶ審査員 5 人の議論。Round 1 で各自が調べ物を 2 件選び、結果は本人だけが知る。
- shared_living_0002: 同居者 5 人がごみ置き場の取り決め 3 案 (A〜C、Round 3 で公開) から 1 つ選ぶ議論。構造は上と同じ。

出力: 指定されたファイルに Markdown で。各台本について短い所見と、指示された形式の判定。最後に「7 本のうち、同じ作り方
(例: 1 つのモデルが全文を書いた / 参加者ごとに別の LLM が書いた) と思われるもののグループ分けの推測と根拠」を書く。
鍵ファイル (<setup_id>.key.json) は読まないこと。リポジトリのファイルは変更しないこと。
